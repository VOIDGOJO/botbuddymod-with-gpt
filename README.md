# BotBuddy (Fabric, Minecraft 1.21.11)

Spawn fake-player bots with random Indian / gamer names and control them from a GUI. Press **B** in-game.

## Get the .jar
1. Push this repo to GitHub.
2. Open the **Actions** tab -> latest **Build mod** run -> download the **BotBuddy-jar** artifact.
3. Unzip it, put `botbuddy-1.0.0.jar` and **Fabric API** into your `mods` folder.

## Command chat
follow [me|name], attack [me|name], guard, stop, come, look, jump, sneak, say <text>,
gamemode <s|c|a|sp>, kit <name>, give <item> [count], clear, remove, help
